# dsh-platform-balance

[English](README.md) | Русский

Плагин для Web GUI [DeepSeek Harness](https://github.com/deepseek-ai): показывает баланс
DeepSeek Platform во всех валютах кошельков (USD и юани), конвертирует его в рубли по
официальному курсу ЦБ РФ и показывает оценку расхода за текущую сессию и за текущие сутки.

В интерфейсе появляются две вещи:

- **плавающая карточка** справа снизу — баланс по каждому кошельку, итог в рублях, курс ЦБ,
  расход за сессию и за сутки. Карточка сворачивается в одну строку и не закрывает кнопки
  отправки сообщения: она поднимается над композером, когда тот прижат к низу экрана;
- **пилюля в шапке открытой сессии** — компактно `≈ 153 ₽ · сессия 5,58 ₽ · сутки 15,25 ₽`.
  Клик по пилюле сворачивает/разворачивает карточку. Пилюля видна только внутри диалога,
  карточка — на всех экранах.

## Где берутся данные

| Что | Источник |
|---|---|
| Баланс | сервис аккаунта DSH (`deepseekAccount.getBalance`, браузерный вход без API-ключа); если аккаунт не авторизован — `DEEPSEEK_API_KEY` и `https://api.deepseek.com/user/balance` |
| Курс ЦБ | официальный XML ЦБ РФ `https://www.cbr.ru/scripts/XML_daily.asp`, курсы USD и CNY к рублю |
| Расход сессии/суток | журналы сессий DSH (`ctx.sessionPersistence`): токены из `assistant/message` × официальные цены DeepSeek в CNY |

Плагин ничего не отправляет наружу, кроме двух запросов: ЦБ РФ (курс) и, при отсутствии
аккаунта, `api.deepseek.com` (баланс). HTTP-маршруты плагина доступны только с loopback и
только same-origin — чужая вкладка браузера баланс прочитать не может.

## Курс ЦБ и кэш

- Курс хранится в файле `$DSH_HOME/cache/platform-balance/cbr.json`
  (по умолчанию `~/.dsh/cache/platform-balance/cbr.json`) и переживает перезапуски.
- Обновление — каждый день в **18:00 по Москве** (таймер в host-части плагина).
  Это же время считается границей «свежести» кэша.
- Если кэша нет — курс запрашивается при первом обращении (и прогревается сразу после
  старта плагина).
- Если сеть недоступна, показывается последний сохранённый курс с пометкой «устарел»
  (курсы и пересчёт в рубли остаются на экране); виджет не остаётся пустым.
- После неудачного запроса запросы с экрана притормаживаются на 2 минуты, чтобы опрос
  раз в минуту не висел по 10 секунд на таймауте; фоновое обновление повторяется через
  15 минут, кнопка «обновить» пробует сразу.
- В кэше лежит дата котировки ЦБ (`date`) и все курсы из ответа; в браузер отдаются только
  USD, CNY и валюты кошельков.

## Расход — это оценка

DeepSeek не отдаёт стоимость запроса в журнале сессии, поэтому расход считается по токенам
и официальной таблице цен (CNY за 1 млн токенов), с учётом:

- пиковых и непиковых часов (пик — 09:00–12:00 и 14:00–18:00 по Пекину, цена ×2);
- перехода на пиковое ценообразование с 2026-08-17;
- снижения цен Flash с 2026-09-10 (и «пик только по будням»);
- маршрутизации `deepseek-v4-pro` на Flash-цены с 2026-09-14.

Таблица цен живёт в [`lib/pricing.js`](lib/pricing.js); при изменении прайса DeepSeek
правится только она. Цифры в интерфейсе помечены `≈`, это оценка, а не счёт.

Учитываются и вызовы суммаризации (`compaction/summary`) — они тоже оплачиваются.
У форк-сессий (субагенты с наследованием истории) скопированный «родительский» префикс
журнала пропускается, поэтому суточная сумма не удваивается, а расход форк-сессии
показывает только её собственную работу.

Сутки считаются по локальному календарному дню машины, где запущен DSH (например, Europe/Moscow). В суточную сумму входят все сессии, включая дочерние сессии субагентов,
при этом наследованный префикс форков не считается второй раз. Дневной итог кэшируется
по ревизии журнала и по календарным дням: повторный запрос перечитывает только изменившиеся
журналы, а смена суток пересобирает итог из уже посчитанных дневных корзин без повторного
чтения всего корпуса сессий.

## Установка

Плагин — обычный пакет-бандл DSH; ставится в профиль `web`:

```sh
# из git-репозитория
dsh plugin --profile web add github:keltanas/dsh-platform-balance

# или из локального checkout
dsh plugin --profile web add ~/projects/dsh-platform-balance
```

`dsh plugin` (это обёртка над pnpm) добавит зависимость и допишет бандл в
`~/.dsh/profiles/web/package.json`. Дальше профиль перезагрузится сам (`patchReload: live`),
а открытая страница подтянет клиентскую часть через HMR — для первой установки перезапуск
`dsh web` не нужен. Если страница не обновилась, достаточно F5. Последующие правки
host-части Node кэширует после первого импорта, поэтому применяются при следующем
перезапуске `dsh web` (например, `systemctl --user restart dsh.service`).

Проверка без браузера:

```sh
curl -s http://127.0.0.1:3080/api/platform-balance/overview | jq .
curl -s "http://127.0.0.1:3080/api/platform-balance/session?id=<id-сессии>" | jq .
```

Удаление:

```sh
dsh plugin --profile web remove dsh-platform-balance
```

### Совместимость с dsh-usage-dashboard

Если установлен `@cassius0924/dsh-usage-dashboard`, его плавающий виджет дублирует балансную
карточку — лучше оставить что-то одно. Вернуть старый плагин можно так:

## HTTP API

Все маршруты: `GET`, только loopback + same-origin, `cache-control: no-store`.

## Устройство

```
lib/index.js      host-плагин: HTTP-маршруты, TTL-кэши, таймер ЦБ, прогрев кэша
lib/cbr.js        загрузка/парсинг XML ЦБ, кэш-файл, расписание 18:00 МСК
lib/wallet.js     баланс через аккаунт DSH с фолбэком на DEEPSEEK_API_KEY
lib/usage.js      чтение журналов сессий, оценка расхода за сессию и сутки
lib/pricing.js    официальные цены DeepSeek, пиковые/непиковые часы
lib/http.js       JSON-ответы и same-origin проверка
lib/client.js     браузерная половина: карточка и пилюля на React
cordis.patch.yml  bundle-слой: одна Loader-строка для обеих половин
test/             node:test — ЦБ, цены, агрегация расхода, кошельки, HTTP
```

Host-часть использует сервисы `webServer`, `credentials`, `sessionPersistence` и
опциональный `deepseekAccount`. Клиентская часть не требует npm-зависимостей: React и
`react/jsx-runtime` приходят из таблицы общих модулей DSH.

## Разработка

```sh
git clone https://github.com/keltanas/dsh-platform-balance.git
cd dsh-platform-balance
node --test                # 38 тестов: ЦБ, цены, расход, баланс, HTTP, host-маршруты
node --check lib/*.js      # синтаксис
```

Проверка на живом GUI после правки `lib/client.js` — просто F5 в браузере: HMR пересоберёт
bundle по mtime. Правки host-части (`lib/index.js` и соседние модули) Node кэширует после
первого импорта, поэтому применяются при следующем **перезапуске** `dsh web`
(например, `systemctl --user restart dsh.service`). Первая установка плагина подхватывается
живой перезагрузкой профиля без перезапуска.

## Ограничения

- Расход — оценка, а не биллинг; цены могут отставать от изменений прайса DeepSeek.
- Если платформа вернёт кошелёк в валюте без курса ЦБ, RUB для него будет `null` («— ₽»).
- Плагин не хранит историю баланса и не прогнозирует «на сколько дней хватит» — это
  отдельная задача.
- Сутки считаются по часовому поясу машины с DSH, а не по часовому поясу браузера.
