# dsh-platform-balance — дизайн и решения

Дата: 2026-11-12. Статус: реализовано и проверено на живом DSH Web GUI.

## Задача (со слов пользователя)

Плагин для интерфейса DeepSeek Harness, который:

1. показывает текущий баланс DeepSeek Platform во всех валютах (USD и юани);
2. конвертирует баланс в рубли по курсу ЦБ РФ;
3. курс ЦБ обновляет в 18:00 по МСК и хранит в кэше/файле; если кэша нет — запрашивает
   при первом обращении;
4. показывает расход за текущую сессию и за текущие сутки.

## Согласованные уточнения

- Размещение: **плавающая карточка + пилюля в шапке открытой сессии** (выбор пользователя).
- Старый `@cassius0924/dsh-usage-dashboard` **отключить/убрать**, чтобы не было двух
  виджетов с балансом (выбор пользователя).
- ЦБ РФ = официальные курсы `cbr.ru` (USD/CNY → RUB).
- Расход — оценка по токенам из журналов сессий и официальным ценам DeepSeek в CNY,
  с конвертацией в RUB. В интерфейсе помечается `≈`.
- Подписи виджета — на русском (пользователь русскоязычный), числа в `ru-RU`.

## Классификация

Задача — новый подсистемный артефакт (новый пакет-плагин DSH), поэтому процесс
архитектурный: исследование контекста → дизайн → утверждение пользователем → реализация.
Утверждение дизайна получено до написания кода (два вопроса + подтверждение).

## Архитектура

Плагин — обычный DSH-пакет с двумя половинами на одной Loader-строке:

- **host** (`lib/index.js`, Node): сервисы `webServer`, `credentials`,
  `sessionPersistence`, опциональный `deepseekAccount`; HTTP-маршруты `/api/platform-balance/*`,
  кэши с TTL, таймер обновления курса, прогрев кэша.
- **client** (`lib/client.js`, браузер): bundle-формат `window.__ModuleLoader__.load`,
  React из таблицы общих модулей, сервис `slots`; регистрирует карточку в `shell.overlay`
  и пилюлю в `conversation.session.header.utilities`.

### Почему не расширили старый дашборд

Старый плагин закрывает широкую статистику (модели, кэш, картинки, heatmap), но не умеет
USD-кошельки, курс ЦБ и рубли. Новый плагин — маленький, сфокусированный, без копирования
обширной аналитики; старый было решено убрать из профиля.

### Альтернативы, которые отклонили

- **Читать API старого плагина** (`/api/dsh-usage-dashboard/session`) — хрупкая связь между
  плагинами; новый плагин должен работать сам.
- **Считать расход как дельту баланса** — ломается от пополнений, бонусов и параллельных
  сессий; оценка по токенам точнее для «сколько стоит эта сессия».
- **Хранить курс в памяти** — не переживает перезапуск и не даёт офлайн-фолбэка.
- **Кнопка обновления вручную** — пользователь просил автоматическое обновление в 18:00.

## Ключевые решения

### Курс ЦБ

- Источник: `https://www.cbr.ru/scripts/XML_daily.asp` (windows-1251, `Nominal`/`Value`).
- Файл кэша: `$DSH_HOME/cache/platform-balance/cbr.json` (по умолчанию `~/.dsh/...`).
- Свежесть: запись валидна, если `fetchedAt >=` последнего прошедшего 18:00 МСК
  (МСК = UTC+3 без перехода на летнее время; 18:00 МСК = 15:00 UTC).
- Расписание: setTimeout на следующую границу 18:00 МСК; после успеха — следующие сутки;
  после неудачи (в т.ч. когда отдан устаревший кэш) — повтор через 15 минут.
- Нет кэша → запрос при первом обращении (плюс прогрев через 1.5 с после загрузки плагина).
- Ошибка сети → отдаём последний кэш с `stale: true` и ошибкой; в UI пометка «устарел».
- Запись атомарная (`tmp` + `rename`), параллельные запросы дедуплицируются.

### Баланс

- Сначала `ctx.deepseekAccount.getBalance(clientMeta)` — использует браузерный вход DSH,
  возвращает все кошельки (`value` + `bonusWallets`, у каждого своя валюта CNY/USD).
- Если аккаунт не авторизован/не ответил — `DEEPSEEK_API_KEY` и
  `https://api.deepseek.com/user/balance` (фолбэк из документации старого плагина).
- Кошельки складываются по валюте: `total`, `granted`, `toppedUp`; к каждой валюте
  применяется курс ЦБ; итог в рублях суммируется.
- TTL кэша 60 с; ошибки не кэшируются.

### Расход

- Источник: `ctx.sessionPersistence.list()` + `open(id, 'read')`; события
  `request/header` (провайдер/модель) и `assistant/message` (`data.usage`).
- Цена: `lib/pricing.js` — CNY за 1 млн токенов, эпохи: flat до 2026-08-17; пик/непик с
  2026-08-17 (окна 09–12, 14–18 по Пекину, ×2); с 2026-09-10 «пик только по будням» и новые
  цены Flash; с 2026-09-14 pro маршрутизируется на Flash-цены.
- Тарифицируются только маршруты платформы DeepSeek (`isDeepSeekRoute`: id провайдера содержит
  `deepseek`, иначе — только модель вида `deepseek*` при пустом провайдере). Запросы других
  провайдеров (ollama, сторонние шлюзы с «deepseek»-моделями) стоимость не имеют и собираются
  в `otherCalls`/`otherTokens`.
- «Сутки» — локальный календарный день машины DSH (например, Europe/Moscow), все сессии, включая
  субагентов. Итог кэшируется по ревизии журнала каждой сессии (перечитываются только
  изменившиеся), TTL 120 с.
- «Сессия» — весь журнал выбранной сессии, TTL 30 с.
- Деньги — оценка (`estimated: true`), валюта CNY; в рублях по курсу CNY ЦБ.

### UI

- Карточка (`shell.overlay`): заголовок, кошельки и итог в ₽, курс ЦБ с датой и временем
  обновления (пометка «устарел»), расход сессии и суток в ¥ и ₽, кнопки обновить/свернуть,
  ошибки текстом. Свёрнутое состояние — одна строка, запоминается в localStorage.
- Карточка поднимается над композером: `useComposerClearance` находит нижний якорный
  контейнер ввода и задаёт `bottom`, чтобы не перекрывать кнопку отправки; на домашнем
  экране остаётся стандартный отступ.
- Пилюля (`conversation.session.header.utilities`): `≈ 153 ₽ · сессия 5,58 ₽ · сутки 15,25 ₽`,
  цветовая точка статуса, tooltip с деталями, клик сворачивает/разворачивает карточку.
- ErrorBoundary у обеих точек: ошибка рендера плагина не ломает GUI.
- Опрос: обзор 60 с, сессия 30 с; при `document.hidden` опрос пропускается.

### Безопасность

- Маршруты только `GET`, только loopback Host и same-origin Origin
  (`sec-fetch-site: cross-site` отклоняется) — чужая вкладка браузера не прочитает баланс.
- `session?id` проверяется регуляркой `[A-Za-z0-9_-]{1,128}`; файловые пути наружу не уходят.
- API-ключ и токен аккаунта никогда не попадают в JSON-ответы.

## API

- `GET /api/platform-balance/overview[?refresh=1]` — кошельки+RUB, ЦБ, расход за сутки.
- `GET /api/platform-balance/session?id=<id>` — расход одной сессии.

Полные примеры ответов — в README.

## Проверка (приёмка)

- `node --test` — 38 тестов: парсер ЦБ (windows-1251, Nominal, дата), границы 18:00 МСК,
  кэш/офлайн-фолбэк и backoff, цены и пиковые окна, агрегация сессий (включая форк-префиксы,
  compaction/summary и смену суток), кошельки и фолбэки баланса, same-origin проверка,
  host-маршруты на фейковом cordis-контексте.
- Живой GUI: `/api/platform-balance/overview` отдаёт USD+CNY, RUB и дневной расход;
  `/session?id=...` — расход сессии; карточка и пилюля отрисованы (проверено в живом GUI).
- Клиентский bundle присутствует в boot-graph (`/plugins/events`) и отдаётся по combo-URL.
- Плавающая карточка не перекрывает кнопку отправки (проверено в живом GUI).
- Старый дашборд не мешает: при наличии его виджет отключается или удаляется.

## Границы

- Оценка расхода не является биллингом.
- Нет истории баланса и прогноза «на сколько дней хватит».
- Сутки считаются по часовому поясу машины DSH, а не браузера.
- Для `link:`-установки путь к исходникам плагина должен сохраняться.


## Правки после независимого ревью

Независимый ревьюер нашёл дефекты; все закрыты в исходниках и покрыты тестами:

| Находка | Решение |
|---|---|
| Двойной учёт наследованного префикса форк-сессий в «сутках» и «сессии» | чтение журнала начинается с `handle.inheritedEventCount`; тест на seeded-сессию |
| Ветка «устаревшего» курса ЦБ никогда не отображалась (ошибка рендерилась вместо курсов) | клиент сначала рисует курсы, если они есть, и добавляет пометку «устарел, курс мог измениться»; проверено e2e с замоканным ответом API |
| Нет backoff на пути запроса при недоступности ЦБ (каждый опрос висел до 20 с) | таймаут 10 с + 2-минутный backoff после неудачи, force-обновление по кнопке обходит backoff; тесты |
| Не учитывались оплачиваемые вызовы `compaction/summary` | учитываются со своей моделью/провайдером; тест |
| Полный перечит корпуса сессий на смене суток и после старта | дневные корзины кэшируются на сессию и переживают смену суток; прогрев дневного агрегата после старта; тесты |
| Потенциальный краш пилюли при `spend.day === null`, `null` в суммах | опциональные цепочки и «—» вместо `0,00` при отсутствии значения |
| `refresh=1` игнорировался маршрутом сессии | принудительный пересчёт сессии; тест host-маршрута |
| Trust fence жёстко требует loopback | осознанное ограничение для текущей установки (зафиксировано в README); при не-loopback bind маршруты недоступны |

Важно про живую установку: клиентская половина обновляется через HMR без перезапуска,
а host-половина загружается в память процесса один раз, поэтому правки host-части
применяются при следующем перезапуске `dsh web`.
